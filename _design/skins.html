决策档案摘要

2026-08-10 皮肤评审 + 两轮三方向探索：第一轮（油印紫/玫瑰石墨/特殊色）被否——「都不太行，有没有明媚一点或者活泼一点的色系」； 第二轮明媚系三版获全数采纳——「都还不错，都做进来吧」；老四套优化对照稿获批——「可以直接落地」。 落码新增机制：typeTints（类型词分色，空=旧行为）、accentText（亮 accent 文字级深档，nil=旧行为）。 对比度实算与设计出处注释均在 Theme.swift 内。

2026-08-12 设计评审补丁：三套新皮肤 hover 实测 1.01–1.04 不可辨（同晨光修复前问题）， 分别加深至薄荷 #E6F4EB / 蜜杏 #FAEDD8 / 晨曦金 #FBEFC9（可辨比 1.11–1.14）； 晴日类型色语义归位（链接=天青 #076B86、邮箱=薄荷 #096344，全家族「蓝青=链接、琥珀=图片、绿=邮箱」对齐）； 偏好主题下拉按深/浅分组。

2026-08-12 第三轮探索（skins-explore-v3.html）：四个空白象限各出一方向——雪莓（冷浅）/ 夜柠（暗活泼）/ 碧潭（浓底纸卡）/ 宣纸（中性纸感），宣纸被采纳落码（文字对实算 5.1–14.8:1、hover 可辨比 1.12）。其余三方向存档备选。

2026-08-12 收敛（8 → 5）：重复度评估后删除 晶蓝/青提/晴日——三套明媚系 shelfTint 几乎同值（#FFF9EC/#FFF7E8/#FFF8E6）， 晴日 accent 还与晶蓝（191°）/晨光（203°）挤同一色相带；晶蓝与夜青（时名「午夜青」）同属深蓝家族。留下的五套在底色/accent/结构上完全正交。 被删三套色值存于 git 历史与本档案，被删 id 由 Theme.by(id:) 回退到夜青。

2026-08-12 第四轮（apple-design 镜头，skins-explore-v4.html）：随色（Agency：跟随系统强调色）/ 轻霜（真材质：亮超薄玻璃）/ 石墨（零色相，因深色区重复风险被否）——随色、轻霜被采纳落码。 同轮落码 Apple 语言四项：蜜柑不透明卡（浅透明不叠浅透明）、增强对比度适配（cardBorderEffective ×2.5）、 强透明 shelf 字重补偿（<0.6 → medium）、卡片 transform 换临界阻尼弹簧（damping 1.0 / response 0.3）。

2026-08-12 第五次调整（7 → 5）：晨光退役，轻霜继位为默认浅色与「跟随系统」浅色分身 （浅色基本盘从近实 0.74 升级为真材质 0.55，老用户 daylight id 由 by(id:) 无感迁移到轻霜）；蜜柑删除。 终阵容：夜青 / 纯墨 / 宣纸 / 轻霜 / 随色——深浅各一基本盘 + 纸感 + 真材质 + 机制型，五套零重叠。

2026-08-13 归档清理：过程稿（skins-explore-v3/v4.html、fluid-v1.html、panel-variants-v1.html 等） 已从工作区删除，全部存于 git 历史（本文件与 Theme.swift 注释中引用的探索稿路径按此检索）。 _design/ 只保留最终交付物：本总览 + skins.png + 图标源（icon-v2.html / menubar-icon-v1.png）。
