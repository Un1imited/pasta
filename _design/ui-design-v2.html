PASTA · DESIGN SPEC
UI 设计 v2 · 品牌统一版

基于 v1.4.0 全部功能出的一版完整 UI 设计。核心动作：把菜单栏 icon v1 确立的 「层叠卡片 = 剪贴历史」品牌语言反向统一到 App icon（现行 icon 还是 clipboard 公共符号， 与菜单栏语言脱节）；面板、偏好设置按 Theme.swift 的 token 规范化整理，并提出两处小的体验提案。 所有色值、字阶、文案均取自源码，未发明新值。

01

App Icon · 三个方向

1024 网格 · 圆角矩形 824×824 · 渐变两端同取 hue 203°

A · 剪贴板（现行 · 对照）

v1.4.0 现状。识别成本最低，但用的是 clipboard 公共符号——与 Maccy 等同类难以区分， 且与菜单栏 icon 的「层叠卡片」语言脱节（菜单栏设计稿 v1 里明确写了要避开这个符号）。

B · 层叠卡片推荐

与菜单栏 icon、面板卡片流三处同构：后卡露出的一角就是上一条记录——「历史」由构图直接表达， 不靠符号借义。前卡内容行沿用「一短蓝 + 两长灰」既有语言，蓝行即品牌蓝。

C · 晶蓝玻璃

同一构图换「晶蓝」主题气质：深蓝渐变底（取自 glass 主题四段渐变）+ 玻璃后卡。 更「pro」，但深底小尺寸辨识度弱于 B，作为备选。
